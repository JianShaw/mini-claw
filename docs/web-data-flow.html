逐步调用链

  1. 1. 浏览器发送消息
    React 前端通过 EventSource 发起 POST 请求
    POST /api/chat/stream { "text": "你好", "session_id": "sess_abc" }
  2. 2. Router 构造 InboundMessage
    chat_stream() 调用 web_message() 将用户输入封装为标准 InboundMessage
    web/backend/routers/chat.py → web_message(text, session_id=...)
  3. 3. Gateway 解析会话
    从 InboundMessage.metadata 提取 session_id，从 SqliteSessionStore 加载 Session 对象
    gateway.py → _resolve_session(message) → session_store.get_by_id(id)
  4. 4. Gateway 注入上下文
    依次注入：agent_runtime_profile（专家 prompt）、memory_context（记忆）、skills_listing（技能）到 session.metadata
    _inject_agent_runtime_profile → _inject_memory_context → _inject_skill_context
  5. 5. Agent Runner 构建消息列表
    _build_messages() 按 system prompt → summary → memory → skills → history 顺序组装 messages[]
    deepseek.py → _build_messages(session)
  6. 6. 流式调用 LLM API
    将 messages[] 发送给 DeepSeek API，stream=True，逐 chunk 接收
    client.chat.completions.create(messages=..., stream=True)
  7. 7. 解析流式响应 → StreamChunk
    每个 chunk 的 delta 被分类为 thinking / content / tool_calls，包装为 StreamChunk 向上 yield
    yield StreamChunk(type="content", text=delta.content)
  8. 8. 工具调用循环（如需要）
    若 LLM 返回 tool_calls → 执行工具 → 将结果追加到 messages → 再次调用 LLM，最多循环 max_tool_iterations 次
    yield StreamChunk(type="tool_call") → execute → yield StreamChunk(type="tool_result")
  9. 9. SSE 回传浏览器
    Gateway handle_stream yield 每个 StreamChunk → Router 序列化为 SSE event → 浏览器实时渲染
    yield {"data": '{"type":"content","text":"..."}'} → data: [DONE]
  10. 10. 后处理 & 持久化
    流结束后，将完整 assistant 回复追加到 session.history，调用 session_store.save() 持久化
    session.history.append(ChatMessage(...)) → session_store.save(session)

SSE 事件类型

type 含义 前端处理
thinking LLM 推理过程（DeepSeek thinking mode） 折叠面板显示思考过程
content 正式回复内容 逐字追加到聊天气泡
system 系统事件（auto-compact 等） 状态栏提示
tool_call 工具被调用（显示函数名） 加载动画 + 工具名称
tool_result 工具执行结果 折叠显示返回值
[DONE] 流结束标记 关闭 EventSource 连接
