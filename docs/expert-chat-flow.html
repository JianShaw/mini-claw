1
浏览专家列表
Frontend — ExpertMarketplace.tsx
组件挂载时请求专家列表
GET /api/v1/experts
web/backend/routers/experts.py → ExpertService.list_experts() → SqliteExpertStore.list_all()
返回 bundled 专家列表（name, display_name, description, meta）
Frontend — ExpertMarketplace.tsx
同时请求已有 Agent 列表
GET /api/v1/agents
web/backend/routers/agents.py → SqliteAgentStore.list_all()
用于判断专家是否已安装（能否直接创建对话）
2
安装专家（如果未安装）
Frontend — ExpertMarketplace.tsx
用户点击"安装"按钮
POST /api/v1/experts/:name/install
web/backend/routers/experts.py → ExpertService.install_bundled(name)
从 bundled 目录加载专家配置，写入 SQLite expert 表
3
创建 Agent + 创建对话
Frontend — ExpertMarketplace.tsx
用户点击"创建对话"按钮
handleCreateAgent(expertName) 被调用
Frontend
检查是否已有该专家的 Agent
agents.find(a => a.source_expert === expertName)
有 → 跳过创建，直接用已有 agent.id
无 → 调用 POST /api/v1/agents
API — agents.py
创建 Agent（如果需要）
POST /api/v1/agents body: {"expert_name": "code-helper"}
web/backend/routers/agents.py → AgentFactory.create_from_expert()
claw/agent_runtime/factory.py
从 Expert 模板复制 system_prompt、enabled_tools、enabled_skills
写入 SqliteAgentStore，返回 AgentConfig（含 agent.id）
API — conversations.py
创建对话（绑定 agent_id）
POST /api/v1/conversations body: {"agent_id": "ag_xxx"}
web/backend/routers/conversations.py
→ Gateway.create_session_for_agent(WEB_PEER_KEY, agent_id, channel=..., ...)
→ claw/session.py create_session_from_identity() 生成 Session
→ SqliteSessionStore.save() 持久化
→ set_active() 设为活跃
返回 {"session_id": "sess_xxx", "agent_id": "ag_xxx"}
Frontend
导航到聊天页面
navigate(`/conversations/${conv.session_id}`)
React Router 渲染 ChatWindow 组件，传入 sessionId
4
加载对话历史
Frontend — ChatWindow.tsx
组件挂载，加载历史消息
GET /api/v1/conversations/:session_id
web/backend/routers/conversations.py → Gateway.get_session_by_id()
→ SqliteSessionStore.get_by_id() 含完整 history
返回 {"session_id", "agent_id", "messages": [{role, content}, ...]}
5
发送消息 → 流式回复（核心流程）
Frontend — ChatWindow.tsx
用户输入消息，点击发送
handleSend() 被调用：清空输入框、添加用户消息到列表、设置 streaming=true
Frontend — api/client.ts
发起 SSE 流式请求
POST /api/v1/chat/stream
body: {"session_id": "sess_xxx", "text": "用户消息"}
使用 fetch + ReadableStream 读取 SSE 事件流
web/frontend/src/api/client.ts streamChat()
API — chat.py
接收请求，转为 PlatformEvent
web/backend/routers/chat.py
WebTransport.receive(text, session_id) → PlatformEvent
ChannelProcessor.process_stream(event) → AsyncIterator<StreamChunk>
SseEncoder 逐个编码 chunk 为 SSE 格式返回
ChannelProcessor
去重 → 适配 → 校验 → 过滤 → 转发 Gateway
claw/processor.py process_stream()
1. 去重：InMemoryDedupeStore 检查 event_id
2. 适配：WebAdapter.to_inbound_message(event) → InboundMessage
3. 补充元数据：transport / event_id / received_at
4. 校验：channel / account_id / peer_id / sender_id / message_id 非空
5. 过滤：bot 消息、系统事件跳过
6. 转发：Gateway.handle_stream(inbound)
错误策略：ErrorPolicy.RAISE（向上抛异常，Router 外层 catch 并 encode_error）
RuntimeGateway
解析 Session + 注入 Agent 配置
claw/gateway.py handle_stream()
1. _resolve_session(message)：从 metadata["session_id"] 找到 Session
2. _auto_compress_if_needed：检查 token 是否超限，超过则自动压缩
3. _inject_agent_runtime_profile(session)：AgentResolver 按 session.agent_id 解析运行配置
  → 从 SqliteAgentStore 加载 AgentConfig
  → 转为 RuntimeProfile（system_prompt, model_config, enabled_tools/skills）
  → 写入 session.metadata["agent_runtime_profile"]
ContextBuildingAgentRunner（wrapper）
注入运行时上下文（memory + skills）
claw/agent_runtime/wrapper.py
RuntimeContextBuilder.build(session, message)
1. _inject_memory_context：MemoryManager 构建记忆上下文 → session.metadata["memory_context"]
2. _inject_skill_context：SkillsRegistry 构建技能索引 → session.metadata["skills_listing"]
  （仅 Layer 1 轻量索引，完整指令由 LLM 通过 load_skill 工具按需加载）
→ 委托 inner runner (DeepSeekAgentRunner) 执行
DeepSeekAgentRunner
构建 LLM messages → 调用 DeepSeek API → yield StreamChunk
claw/deepseek.py run_stream()
1. _build_messages(session)：
  • system: summary → memory_context → skills_listing → agent profile
  • history: session.history 中的 user/assistant/tool 消息
2. 调用 DeepSeek API（OpenAI 兼容接口，stream=True）
3. 工具调用循环：
  • LLM 返回 tool_call → 执行工具 → tool_result 追加 → 继续调用
  • 直到 LLM 返回纯文本内容
4. 逐 token yield StreamChunk(type="content"|"thinking"|"tool_call"|"tool_result")
RuntimeGateway
流结束后：保存 history + 更新 memory
claw/gateway.py handle_stream() 后半段
1. 聚合 full_text + full_thinking
2. session.history.append(ChatMessage(role="assistant", content=full_text))
3. _maybe_update_daily_memory(session) — 按策略更新 daily memory
4. session_store.save() — 增量追加新消息到 SQLite
5. delivery.send() — Web 端是 NoopDelivery（SSE 已直接返回）
API — chat.py
SSE 编码返回
claw/channels/web/delivery.py SseEncoder
每个 StreamChunk → {"data": "{\"type\":\"content\",\"text\":\"...\"}"}
结束标记 → {"data": "[DONE]"}
Frontend — ChatWindow.tsx
逐 chunk 更新 UI
for await (const chunk of streamChat(...))
• content → full += chunk.text → setStreamText(full)
• error → full += "[错误] " + chunk.text
流结束后：写入 messages 数组，streaming=false
视觉反馈：发送按钮旋转 SVG → "思考中..." 三点动画 → 流式气泡 + 闪烁光标 ▌
API 调用时序汇总
步骤 API 核心模块
1. 浏览专家 GET /api/v1/experts ExpertService → SqliteExpertStore
2. 安装专家 POST /api/v1/experts/:name/install ExpertService.install_bundled()
3. 创建 Agent POST /api/v1/agents AgentFactory.create_from_expert() → SqliteAgentStore
4. 创建对话 POST /api/v1/conversations Gateway.create_session_for_agent() → SqliteSessionStore
5. 加载历史 GET /api/v1/conversations/:id Gateway.get_session_by_id() → SqliteSessionStore
6. 聊天（SSE） POST /api/v1/chat/stream WebTransport → Processor → Gateway → ContextBuilder → DeepSeekRunner
